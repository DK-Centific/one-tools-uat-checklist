# One Tools UAT checklist

Interactive checklist for the One Tools UAT window (16 to 29 Nov 2026).

Use the hosted page, or download `index.html` and open it in a browser (it also works offline as a local file):

**https://dk-centific.github.io/one-tools-uat-checklist/**

Filter by My view or Primary owner, mark Pass / Fail / Blocked, and record bugs in the Feedback Guide format. Marks are stored only in your browser on this device.

If your lead shares a Sync link, Read link, and team code, paste them once under Connect to sheet so filed tickets can show on each step. Those values stay in your browser. This page never embeds them.

Do not paste account passwords or personal email addresses into notes or tickets from this page.

This page does not embed Jira credentials, a sheet sync link, a read link, or a team code.
